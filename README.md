# Burrow

A visual designer and template manager for [Marmot](https://github.com/ShelfFoundry/Marmot) label templates.

> [!WARNING]
> Burrow is a _very_ early stage project. No promises about roadmap, support, or accepting contributions.

## Status

- Designer UI: SolidJS SPA (stub)
- Engine: Odin, currently supports selecting, resizing, and moving rectangles, lines, and circles
